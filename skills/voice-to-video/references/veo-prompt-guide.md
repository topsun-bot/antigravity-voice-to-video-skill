# Omni 1.2 Flash & Veo 3.1 导演提示词与反穿帮指南 (v3.3)

写好动态视频提示词的核心是**让画面自己讲故事、让空间站位和逐秒动作完全明确**，而不是套用千篇一律的“科幻蓝光 + 旁白解说”。

## 1. 选对模型档位（2026-11 实测更新）
- **`Omni 1.2 Flash`（首选主力，3s–15s）**：单次直出最长 **15 秒**长镜头（`720p · 15s` 约 60 点数，`1080p` 重塑 `<=10s` 免费、`11–15s` 仅 +5 点数），适合长连贯舞蹈/跟拍、精准时间轴分段（`[0-5s] ... [5-10s] ...`）与锁定参考图生成。
- **`Veo 3.1 - Lite`**：低成本基础动态备选。
- *退场提醒*：`Veo 3.1 - Fast`、`Veo 3.1 - Quality`、`Omni 1.1 Flash` 将于 **2026 年 12 月 5 日**在 Flow 停用。

## 2. 电影级 6 要素 + 站位锚点 + 逐秒时间轴公式

### 2.1 通用单镜 6 要素模板
```text
[运镜 + 景别 + 机位角度] + [【站位】空间左右与道具归属] + [主体神情与逐秒物理动作] + [真实光影四维（方向/软硬/冷暖/明暗）+ 焦段] + [原生声音设计] + [镜头约束]
```
- **先写空间【站位】（防越轴/瞬移）**：明确写清谁在左、谁在右、门/窗在哪一侧、摄影机在哪边、关键道具在谁手里、人物朝哪个方向走，彻底杜绝切镜后左右互换。
- **逐秒动作时间轴（首尾帧/精准卡点必用）**：
  - `0–0.2s`：稳住首帧构图与姿态（消除首帧突跳）；
  - `中间逐秒`：按时间顺序写可观察的物理动作（`plants left heel, pivots 180 degrees, drops into a sharp floor freeze`），少用空洞形容词（`epic`、`amazing`）；
  - `末尾 0.3s`：动作收势落稳（方便切镜或 `Save frame` 接下一镜）。
- **明确光影四维 + 焦段**：写清光的方向（侧光/逆光/顶光）、软硬（柔光/硬聚光）、冷暖（暖钨丝/阴天冷光）、明暗，以及焦段（如 `28mm handheld`、`50mm shallow depth of field`、`85mm detail macro`）。
- **单参考图跨场景「背景/光影强制覆盖法」**：当全片只挂 1 张锁定角色图（如灰底舞室生成的机器人）但需要跨场景换灯光时，显式写入：
  > `matching ONLY the character design from the reference image; completely ignore the reference image's grey background and flood the scene with [target lighting / location / camera angle].`
- **原生声景（纯净成片极关键）**：明确写出有可见物理来源的声音（脚步、关门、鼓点、环境底噪）；**不说话的角色明确标注闭嘴静默**，避免 AI 胡乱张嘴配音。
- **镜头约束**：单镜头保持连贯写 `Single continuous unbroken shot, no scene cuts, no text, no watermarks.`（说台词特写镜头尽量保持固定机位，不乱推拉）。

## 3. AI 视频 16 大高频穿帮避坑清单（写分镜时主动规避）

| 常见穿帮风险 | 为什么容易翻车 | 正确规避写法 |
|---|---|---|
| **双人画面内交叉走位** | 人物遮挡重合瞬间极易换脸/融肢 | 改为前后景错开站位，或拆成正反打两镜 |
| **精细小物件手持/传递** | 易变形、数量飘移或凭空消失 | 道具提前标物理尺寸，或改用大特写单独交代 |
| **大面积镜子/玻璃强反射** | 镜中倒影与主体动作不同步 | 降低镜面反射清晰度或避开直拍镜面特写 |
| **单镜内剧烈换光** | 容易引起闪烁和肤色崩坏 | 光影大变化放到切镜点完成，单镜保持光位稳定 |
| **一句塞 3 个以上连续大动作** | 动作加速变形、后半段来不及做完 | 1 镜只讲 1 个核心动作或 1 次情绪转折 |
| **负面提示词反触发（"不要 XX"）** | 模型容易反而把提到的 XX 画出来 | 用正向描述替代（写"空旷干净的水泥墙"，不写"不要杂物和人群"） |
| **群演动作完全同步** | 剧情片里同一秒举手一眼假 | 写明"错峰先后反应"（齐舞/仪仗题材除外） |
| **不说话的角色胡乱张嘴** | 原生音频头误以为角色在说话 | 明确写 `keeps mouth closed, silent focused expression` |
| **物体凭空瞬移入画** | 起点不在画面内又没写进场方式 | 写清从画面左侧/门外自然走入，或起始就在画面内 |
| **持续性细节中途消失** | 雨滴、帽子、纹身、配饰在半途丢失 | 在每个连续镜头和首尾帧提示词里重复点名保留 |
| **全片全是平视居中构图** | 呆板像证件照幻灯片 | 人物眼睛放 38%/62% 黄金线，严禁连续 3 镜同景别/同运镜 |
| **首尾帧突跳 / 结尾僵硬** | 动作没收住或起势太猛 | 开头 0.2s 稳住起势，结尾 0.3s 落稳定格 |
| **道具比例失真** | 杯子画成盆、手机画成平板 | 道具出图与提示词写明实际厘米数与手握比例 |
| **人物行走方向写反** | "往左/往右"与镜头视角歧义 | 统一按**画面观察者视角**写 `walks from screen-left to screen-right` |
| **风吹动作与手部动作混写** | 画面抖动、物理归因混乱 | 明确动作驱动源（风吹衣角 vs 主动挥臂） |
| **品牌/明星/版权词触发审核** | 直接被 Flow 拦截拒审 | 彻底剔除歌名、艺人名、游戏/影视 IP 名，改用纯粹视觉描述 |

## 4. 多镜头连续性铁律
- 不要写 7 个互不相干的 8 秒碎片！优先规划：
  - **15 秒 `Omni 1.2 Flash` 长镜头** 或 **`Extend` / `Save frame` 尾帧接续**；
  - 同一场景内通过**切换景别与机位角度**（全景定场 → 38%/62% 侧跟中景 → 手部/脚部微距 → 反打反应镜头）营造真正的电影剪辑节奏感。
